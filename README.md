# 🧠 AI-Powered Task Management System

An *intelligent task management system* that uses *Machine Learning (ML)* and *Natural Language Processing (NLP)* to automatically *classify, prioritize, and assign tasks* to users based on their *behavior, deadlines, and workloads*.  

This project combines *AI analytics* with *automation* to make team productivity smarter and data-driven. 🚀

---

## 🌟 Features

- 🔍 *Task Classification:* Automatically categorize tasks using NLP.
- ⚡ *Priority Prediction:* Predict task urgency using ML models.
- 🧮 *Workload Balancing:* Distribute tasks based on user load.
- 📊 *Analytics Dashboard:* Visualize task insights and completion stats.
- 💾 *Database Integration:* Store and fetch tasks dynamically using MySQL.
- 🌐 *Streamlit Frontend:* Interactive UI for task assignment and visualization.
